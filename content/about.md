# About Sujib Shrestha

Sujib Shrestha is a software developer based in Kathmandu, Nepal, specializing in backend systems and generative AI integration, with full-stack experience.

Sujib designs APIs, database schemas, real-time systems, and LLM-powered features. His interests include prompt engineering, retrieval systems, evaluations, and making AI applications reliable in production. He also builds responsive frontends and handles deployment.

## Skills

- Languages: JavaScript, TypeScript, and Python.
- Backend: Node.js, Express.js, Django, REST APIs, WebSockets, and JWT authentication.
- Databases: PostgreSQL, MySQL, MongoDB, Supabase, and Neon.
- Frontend: React.js, Next.js, Tailwind CSS, HTML5, and CSS3.
- AI: LLM API integration, LangChain, retrieval-augmented generation (RAG), vector databases, and prompt engineering.
- Tools: Git, GitHub Actions, Docker, Vercel, VS Code, and Postman.
